# BADA2024 수심 데이터

출처는 국립해양조사원 바다누리 해양정보입니다. [BADA2024 v1.1 원본](https://www.khoa.go.kr/oceandata/oceaninfo/analysis/bada2024Download.do?type=txt&year=2024)

- `BADA2024_v1.1.txt.gz`는 전체 관할해역 원본을 gzip으로 압축한 파일입니다. Git LFS를 사용하며, 압축을 풀면 공백으로 구분된 `LON LAT MSL` 3열과 15,017,635개 격자점이 있습니다.
- `sacheon_namhae_bada2024.csv`는 경도 127.90~128.25°, 위도 34.80~35.05° 범위의 격자점 17,423개를 담고 있습니다. 열은 `lon,lat,depth_m`입니다.
- 격자 간격은 150m이고, 수직 기준면은 평균해수면(MSL)입니다. 양수는 평균해수면 아래 깊이(m)이며 원본 부호를 유지했습니다. 원본 TXT에는 수평 좌표계 식별자가 없습니다.
- 2024년판은 2019~2023년의 신규 측량자료를 반영했습니다. 격자점별 측량 연도는 제공되지 않습니다.

압축 해제한 원본 TXT의 SHA-256은 `93c3b8b9daa8353df69bb27947584348c5dde952858e1da369e2568fb044fe8b`입니다.

`sacheon_depth_grid.json`과 동일한 내용의 gzip 압축본 `sacheon_depth_grid.json.gz`는 사천·남해(경도 127.90~128.25°, 위도 34.80~35.05°)의 213열 × 185행 수심 격자입니다. 간격은 경도 0.00164°, 위도 0.00135°이며, 남서쪽부터 동쪽으로 행을 채운 뒤 북쪽 행으로 이동합니다. 셀 중심을 해안선의 투영 좌표계(KGD2002 / Central Belt 2010)에서 검사해 육지는 `-9999`로 표시했습니다. 마스크는 국립해양조사원 해안선 SHP(2025-12-31 기준)의 선들을 경계로 사용했습니다. 바다 셀은 150m 안에 BADA 점이 있을 때 200m 반경의 원본 점을 거리 제곱의 역수로 가중해 보간하고 소수 둘째 자리로 반올림했습니다. 격자 바깥의 인접 원본 점도 보간에 사용했습니다. 150m 안에 점이 없는 바다 셀은 `null`입니다. 수심 단위는 m이며 평균해수면(MSL) 아래가 양수입니다. [국립해양조사원 해안선 SHP](https://www.data.go.kr/data/15083948/fileData.do)
