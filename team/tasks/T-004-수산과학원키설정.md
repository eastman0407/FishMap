# [작업 T-004] 설정에 '국립수산과학원 키' 입력 칸 추가
- 담당: GPT
- 배경: 수온 보정에 국립수산과학원 실시간 수온 관측소(risa OpenAPI)를 쓰려 함. 이 API는 공공데이터 키가 아니라 국립수산과학원 홈페이지(nifs.go.kr → OpenAPI)에서 따로 받은 키(`key=` 매개변수)가 필요. Claude가 자료 쪽(NIFS 객체, `nifsReset()` 함수)을 동시에 만들고 있음.
- 목표: ⚙️ 설정 > 🔑 키·연결 묶음에서 브이월드 키 칸 아래에 수산과학원 키 칸이 보이고, 저장하면 pref `nifsKey`에 저장되고 `nifsReset()`이 불림.

## 고칠 구역 (app/src/main/assets/index.html)
1. 브이월드 키 칸(약 546~547행, `id="vwIn"`) 바로 아래에 같은 모양으로 추가:
   - 안내 줄(class="empty", 브이월드 줄과 같은 style): `국립수산과학원 실시간 수온 키 (선택 — 섬·만 안쪽 수온을 실측으로 보정)`
   - 입력: `<input id="nifsIn" type="password" autocomplete="off" placeholder="수산과학원 인증키">` + 👁 버튼(`data-eye="nifsIn"`, aria-label·title은 기존과 같게)
2. 설정 열 때(약 4077행 `$('#setBtn').onclick`): 가림 목록 `['keyIn','vwIn']`에 'nifsIn' 추가, 값 채우기 `$('#nifsIn').value=pref('nifsKey','');`
3. `function saveSettings()`: `const nk0=pref('nifsKey',''); setPref('nifsKey',$('#nifsIn').value.trim()); if(nk0!==pref('nifsKey','')&&typeof nifsReset==='function')nifsReset();`
4. 백업 목록 `BAK_PREFS` 배열에 'nifsKey' 추가. 키 보내기 `XFER_KEYS`는 건드리지 말 것(별도 결정 필요).
5. 키 묶음 요약(`#sumKey`)을 만드는 곳이 있으면 찾아서, 수산과학원 키가 있으면 기존 표기 방식대로 함께 표시(없으면 손대지 말 것 — 질문란에 적기).

## 건드리지 말 것
- tempAt, wtemp, wtNear*, wtEnsure, dtObs, dtStations, NIFS 관련 자료 함수(Claude가 작성 중), 유속 계산

- 360px 폭에서 깨지지 않음, 기존 칸 모양·순서 그대로
