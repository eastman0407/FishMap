# [작업 T-002] 화면마다 다른 수온을 하나의 계산으로 통일
- 담당: GPT
- 배경: 검토(T-001) 결과, 같은 자리인데 화면마다 수온 계산이 달라 값이 다르게 보임. 위쪽 칩·계획 카드·조과 기록·추천 점수는 예보만(tempAt), 지점 카드·추천 팝업은 관측소 보정(wtemp)을 씀. 추천 팝업과 추천 점수는 서로 다른 시각을 씀.
- 목표: 수온 '값'을 보여주거나 점수에 쓰는 곳은 모두 `wtemp(lat,lon,th)` 의 `.v` 를 쓴다(없으면 null). 같은 핀의 팝업과 점수는 같은 시각을 쓴다.

## 고칠 구역 (app/src/main/assets/index.html)
1. `function updateWxChip()` (약 1258행): `T`와 내일값 `Tn`을 wtemp(...).v 로. 지도 중심 관측값이 없으면 받아오도록 `wtEnsure(c.lat,c.lng,updateWxChip)` 를 한 번 호출(wtEnsure는 10분 캐시·중복 방지가 있음).
2. 계획 카드 (약 2658행 `T=tempAt(b.la,b.lo,nth)`) → wtemp
3. 조과 기록 저장 (약 2700행 `wt:` 계산) → wtemp
4. 추천 후보 계산 (약 2959행 `T=...tempAt(la,lo,bth)`) → wtemp. `dT`(tempChange, 하루 변화량)는 그대로 둔다(차이값이라 보정이 상쇄됨).
5. 추천 핀 팝업 (약 3165행 `thW`): 점수 계산과 같은 시각(그 후보의 best.w.ms 기준 bth)을 쓰도록. 코드를 읽고 후보 객체에 이미 있는 값으로 맞출 것.

## 건드리지 말 것
- tempAt, wtemp, wtNear, wtEnsure, dtObs, WT_P 함수 본문 (Claude가 동시에 고치는 중. 이름·인자·반환 모양 {v,f,K,src,...}은 유지됨)
- tempChange, tempDelta, sstAt, 유속 계산 전부, 흐름선 그리기

## 합격 기준
- 수온 값 표시·점수용 tempAt 호출이 위 5곳에서 사라짐 (tempAt은 tempChange/tempDelta/wtemp 내부 등에서만 남음)
- 화면 모양·문구 변화 없음
- null 처리 유지(수온 없으면 지금처럼 안 보임)
