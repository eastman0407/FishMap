# [작업 T-001] 수온 알고리즘 검토 (코드 수정 없음 — 보고만)
- 담당: GPT (검토자). 총괄 Claude도 따로 검토해 결과를 맞대 본다.
- 사용자 보고: "수온 알고리즘이 이상하다. 섬 하나에서(섬 주변에서) 수온 차이가 심하다."

## 볼 코드 (app/src/main/assets/index.html, 읽기만)
- tempAt (약 1045행): ROMS 표층 수온 거리가중 평균. 반경 RD.R(969·998·1000행 근처, 확대 수준에 따라 바뀜)
- wtemp / wtNear / dtObs / WT_P (약 1215~1240행): 예보 + K×(가까운 조위관측소 실측 − 관측소 자리 예보) 보정
- sstAt (약 2198행): 위성 수온(NASA MUR) 최근접 칸
- 화면에 수온이 나오는 곳: updateWxChip(약 1257행), wtText 호출(3170·3630행), 3636행 근처 카드, 2658·2700·2959행
- ROMS 점 읽기: 924행 근처 (수온 칸 WK)

## 해 줄 일
1. 섬 주변에서 수온이 크게 달라지거나 튈 수 있는 원인을 코드 근거(행 번호)와 함께 찾는다. 가능성 높은 순으로.
2. 각 원인마다: 어떤 상황에서 몇 ℃쯤 차이가 날 수 있는지 대략 수치로.
3. 같은 자리인데 화면 곳곳에 서로 다른 수온이 표시되는지 확인.
4. 고칠 방향을 1~2줄씩 제안(코드는 쓰지 말 것).
5. 확실하지 않은 건 '추정'이라고 표시.
