# 물흐름 지도 (개인용 안드로이드 앱)

- 지도: Esri 위성지도
- 조류: 국립해양조사원 ROMS 해양예측 (공공데이터포털) — 앱 안 ⚙ 설정에서 인증키 입력
- 기능: 시간대별 물흐름 애니메이션, 현위치, 지역 검색, 즐겨찾기

## 형상관리
요구사항·버전·데이터 이력은 [형상관리.md](형상관리.md) 참고.

## APK 받기
main 브랜치에 올라갈 때마다 GitHub Actions가 APK를 만들어 **Releases** 에 올립니다.
폰에서 저장소 → Releases → 최신 `fishmap-N.apk` 다운로드 → 설치 (출처를 알 수 없는 앱 허용 필요).

## 처음 설정
1. 공공데이터포털에서 "국립해양조사원_ROMS 수치예측모델 조회" 활용신청
2. 일반 인증키(Decoding) 복사
3. 앱 ⚙ → 키 붙여넣기 → **연결 시험**
4. 지도를 9단계 이상 확대하면 실제 조류 표시
