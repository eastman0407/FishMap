# 실기기 점검 5줄 (U-37, 2026-11-21~)

자동 시험(빠른 시험·전체 시험·디자인 자동 검사)으로는 알 수 없는 것만 폰에서 확인한다.
업데이트마다 아래 **공통 5줄**을 하고, 그 빌드에서 바뀐 곳은 '이번 빌드' 줄을 더한다. 결과는 형상관리.md 5장 '실기기 확인' 칸에 적는다.

## 공통 5줄 (매 빌드)
1. **한 손·햇빛:** 바닷가에서 한 손으로 바다를 찍고 → 상태창의 다음 정조 시각을 5초 안에 읽을 수 있나 (화면 밝기 자동 그대로)
2. **제스처 뒤로가기:** 상태창 → 📈 그래프 → 출조 도우미를 연 뒤, 화면 가장자리에서 밀면 맨 위 창부터 하나씩 닫히고, 다 닫히면 앱이 뒤로 가나
3. **손맛:** 시트·지금 카드를 끌 때 손가락을 바로 따라오고, 놓으면 부드럽게 멈추나. 버튼이 누른 즉시 눌린 모양이 되나
4. **진동·알림:** 입질 기록·추천 완료 때 짧은 진동이 오나, 🔔 알림이 잠금 화면에서도 오나
5. **끊김:** 비행기 모드로 켜도 본 곳의 흐름·조석이 보이고 '인터넷이 끊겼어요' 안내가 뜨나, 다시 켜면 새로 받나

## 이번 빌드 (빌드마다 바꿔 적기)
- build-49: 상태창이 자리를 안 가리는지 · 그래프 시트 높이 · 물방울 · 시간 막대 자정 끊김 · ⚙️ 조석 시험 6가지 결과 캡처(H-10)

## 현장 과업 시험 (가끔, UX 가이드 7장)
- ① 포인트 찍고 다음 정조 시각 말하기(5초) ② 주변 추천 1등 자리 길 안내 열기 ③ 입질 기록 후 어종 적기 — 막힌 곳을 한 줄씩
