# 앱 개발 표준 — 디자인 기준과 형상관리 (공통)

원본(계속 고치는 곳): https://claude.ai/artifact/5Efw4RbXGuAhH6LVJii8sc
이 파일은 저장소용 요약본이에요. 내용이 다르면 원본이 맞아요.

새 앱을 만들 때 쓰는 법:
1. `docs/형상관리_템플릿.md`를 복사해 `형상관리.md`를 만든다.
2. 첫 화면을 그리기 전에 앱의 **목적**과 **주고 싶은 감정**을 한 줄로 정한다.
3. 화면은 이름표 규칙(M·P·L·F)으로 이름을 붙이고 테두리 그림을 그린다.
4. 화면이 바뀌는 빌드마다 아래 점검표를 통과시키고 '검증 기록'에 적는다.

## 1. 철학 — HIG 8원칙 (2026-06 개정)

| 원칙 | 우리 규칙 |
| --- | --- |
| 목적 | 기능마다 "왜 필요한가"를 REQ에 적고, 핵심 3개만 맨 앞에 |
| 주도권 | 1초 넘으면 진행 표시, 지우기·바꾸기는 되돌리기 |
| 책임 | 키는 폰에만, 추정은 "(추정)", 안전 정보는 확실하게 |
| 익숙함 | 표준 패턴(시트·탭·뒤로가기), 누르면 0.1초 안에 반응 |
| 유연함 | 누르는 범위 44pt(48dp)+, 색만으로 뜻 전하지 않기, 끌기에는 톡 대안 |
| 단순함 | 한눈에 → 펼쳐서 → 들어가서, 한 줄 원칙 |
| 공들임 | 자동 시험 + 실기기 확인, 손가락을 따라가는 움직임 |
| 즐거움 | 기록·저장·완료 순간에만 짧은 반응·진동 |

감성 3단계(노먼): 본능(첫인상) → 행동(쓰는 동안) → 반성(쓰고 나서).

## 2~5. 화면·숫자·동작·표기 (요약)

- 바텀 시트 1개, 주인공(지도 등) 크기 고정, 화면당 주요 버튼 1개, 선택지 7개 안팎
- 누르는 범위 44×44+(안드로이드 48), 버튼 사이 8+, 글자 13/16/11, 대비 4.5:1
- 끌기: 8px 넘으면 끌기, 1/4 넘거나 0.5px/ms 튕기면 끝까지, 0.2~0.3초 스냅
- 창 닫기 3가지(× · 뒤로가기 · 바깥), 확인 창보다 되돌리기, 못 누르는 상태는 흐리게+이유
- 그림 글자 뒤 FE0F, 숫자는 다른 칸, "(추정)" 같은 모양, 한 줄 넘치면 문구 줄이기
- **정보는 한 집**: 한 정보는 한 곳에서 자세히, 다른 곳은 한 줄 요약만(내비 지도·계기판·HUD처럼 여기저기 같은 걸 다 띄우지 않기). 새 정보를 넣을 땐 '이 정보의 집은 어디?'부터 정함
- 떠 있는 작은 창(상태창)은 가리키는 자리를 가리지 않게(위 → 안 되면 아래), 꼬리로 자리를 가리키고, 지도를 움직이면 따라감

## 6. 이름표 규칙

M=메인 구역, P=창, L=지도 표시물, F=기능, REQ=요구사항. 새 부분은 다음 번호, 지운 번호는 다시 안 씀.
이름표 = 표 + 테두리 그림(실제 아이콘).

## 7. 형상관리 절차

요청 → (문제면) 고장탐구 / (기능이면) 초안 → 승인 → 구현 → 시험 → 기록 → 빌드 → 실기기 확인.
작업 규칙 1~7은 `docs/형상관리_템플릿.md` 맨 위에 있어요.

## 8. 화면을 바꿀 때마다 점검표

**철학**
- [ ] 앱 목적에 맞고, 빼도 되는 것을 더하지 않았다
- [ ] 추정·불확실한 값은 "(추정)"으로 표시했다

**터치·반응**
- [ ] 새 버튼·손잡이·체크의 누르는 범위 44×44 이상 (자동 측정)
- [ ] 누르면 0.1초 안에 눌린 모양
- [ ] 1초 넘는 일은 진행 표시, 끝나면 결과 알림
- [ ] 못 누르는 상태는 흐리게
- [ ] 끌기에는 톡 대안, 시스템 제스처와 안 겹침

**화면·표기**
- [ ] 폰 폭(390~411px)에서 겹침·잘림 없음 (자동 측정)
- [ ] 한 줄 원칙: 넘치면 문구 줄임
- [ ] 그림 글자 FE0F 빠진 것 0개 (자동 검사)
- [ ] 정보는 한 집: 같은 정보가 두 곳에 자세히 나오지 않음(다른 곳은 한 줄 요약)
- [ ] 시안은 그려서(실제 폭) 글자 대비·넘침·겹침을 재 본 뒤에 보여 줌 — 재지 않은 것을 '확인했다'고 하지 않음
- [ ] 색만으로 뜻 전하지 않음, 대비 4.5:1
- [ ] 창을 펴고 접어도 주인공 크기·위치 그대로
- [ ] 창은 세 방법으로 닫힘

**감성**
- [ ] 완료·저장·기록 순간에 짧은 반응
- [ ] 움직임 0.2~0.3초, 손가락을 따라감
- [ ] 지우기·바꾸기에 되돌리기

**기록**
- [ ] 이름표(표·그림) 갱신, 빌드 이력에 "이름표 갱신"
- [ ] 자동 시험 전체 재실행, 실기기만 볼 수 있는 것은 '실기기 확인 필요'

## 9. 바다흐름지도 적용 현황

원본 문서 9장 참고. 다음 개선 후보: 작은 누르는 범위(▴·×·토글·손잡이·체크·🔔☆🎣·⌕), 눌린 모양, 되돌리기, 진동, 스프링 움직임, 못 누르는 상태, 권한 설명, ⚙ 설정 단순화. (초안 → 승인 뒤 구현)
