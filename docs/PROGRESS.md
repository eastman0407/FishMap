## 2026-11-26 세션 (build-77 → build-84)

**11-25 인수인계 대기 항목 묶음(검토 1~10) — build-77~78**
- 흐름선: 꼬리·굵기·밀도 복원, 거의 정조 먼지↓, 자료부족 선 고정. (이후 build-78에서 유속 시현 전체를 build-65 방식으로 되돌림 — 사용자 지시)
- 지도 도구 네 아이콘(밤낚시·내 위치·출조·지도 보기)을 같은 1.8px 윤곽 SVG로 통일, 내 위치 4상태(기본·찾는 중·현위치 이동·따라가기)·화살표 고정·`.on` 안 꺼지던 결함 수정.
- 글꼴 크기 옵션(작게 0.9·보통 1.0·크게 1.15, `--fs` 토큰, 글자만 커지고 지도·터치 불변), 설정·백업 포함.
- 상단 카드·레이어 시트 테두리 겹침, 날씨 카드 페이지 안정화(데이터 늦게 와도 안 튐).
- 형상관리·검증 기록 갱신, 화면 이름표를 외부 문서 → 저장소 이미지(`docs/이름표.md` + `tools/make_nametags.py`)로 이전.

**유속 시현 복원·개선 — build-78~80 (방정식은 그대로)**
- build-78: 유속 시현을 build-65 방식으로 되돌림(단일 캔버스·지수 감쇠 꼬리·1.5px·촘촘·√속도 이동 보정). 움직임 dt 기준(60fps=build-65, 120Hz 안 빨라짐).
- build-80: ① 확대할수록 입자가 나뉘며 촘촘(줌 비례, 상한 3600) ② 확대 전환 끊김 제거(이전 캔버스 배율 맞춰 이어 그림) ③ 항내 계산 중엔 예보 방향을 흰 선으로 표시, 완료 시 색.

**지금 카드 칩 — build-81~84**
- build-81: 칩을 한 줄 고정(줄바꿈 금지)으로 바꿔 값이 갱신돼도 카드 높이 불변(74px).
- build-82: 칩을 폭에 맞게 늘려 채움(오른쪽 여백 제거) — 사용자 선택 ③.
- build-84: 균등 늘림이 긴 칩을 자르던 것(…)을 **내용 비례 늘림(flex 1 1 auto)**으로, 조석 칩의 관측소 이름은 빼서(지도 🌊 마커에 있음) 한 줄에 다 들어가게. 잘림 0.

**지도 보기 시트 버튼 — build-83**

**방정식 검토 결론**
- GPT가 유속 방정식을 망가뜨리지 않았음을 확인. 핵심 LBM·보간 수학은 build-65와 동일. GPT 변경은 결정성(고정 블록·회차·고정 격자) 향상과 지점 넛징 추가뿐. 모델은 build-65 때부터 현장 실측 검증이 안 된 상태(그대로).
