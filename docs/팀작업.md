# 팀 작업 방식 (Claude 총괄 · GPT·Grok 구현)

사용자는 **Claude하고만 대화**한다. 업무 지시, 결과 검토, 합치기, 배포는 Claude가 맡는다.
GPT와 Grok은 Claude가 API로 부르는 구현 담당 팀원이다.

## 역할
| 담당 | 맡는 일 | 맡지 않는 일 |
|---|---|---|
| Claude (총괄) | 시스템 설계, 작업지시서 작성, 일부 구현(유속 계산·어려운 부분·통합), 코드 리뷰, QA, 형상관리.md, 커밋·배포 | — |
| GPT (주 구현) | 화면·UI 기능, 일반 로직 | 유속 방정식, 지시서 밖 수정 |
| Grok (보조 구현) | 독립 함수, 자료 변환 스크립트(`tools/`), 시험 코드(`test/`), 대안 구현 비교 | 유속 방정식, 지시서 밖 수정 |
| 사용자 | 설계 승인, 우선순위 결정 | — |

## 흐름
1. 사용자 요청 → Claude가 재현·원인 확인 후 **설계 초안**(화면·동작·영향·시험 계획)을 보고 (작업규칙 2·3)
2. 사용자 승인
3. Claude가 작업을 쪼개 `team/tasks/T-NNN.md` 작성 (고칠 구역, 건드리지 말 것, 합격 기준)
4. Claude가 `team.py ask`로 팀원에게 전달 (관련 코드 구역만 첨부)
5. 답변을 `team.py apply --dry`로 확인 → Claude 코드 리뷰
   - 불합격 시 피드백 파일을 써서 `ask --feedback`으로 다시 맡김 (최대 2회, 그래도 안 되면 Claude가 직접 구현)
6. 적용 → 브라우저 QA·단위시험 → 형상관리.md·이름표 갱신
7. 커밋(메시지에 담당 팀원 표기) → 빌드·배포 → PROGRESS.md 기록

## 규칙
- **main 푸시는 Claude만.** 팀원 코드는 리뷰와 QA를 통과해야 들어간다.
- **유속 계산은 팀원에게 맡기지 않는다.** 사용자가 명시적으로 지시할 때 Claude가 직접 한다.
- 파일이 `index.html` 하나뿐이므로, 같은 구역을 건드리는 작업은 동시에 맡기지 않는다.
- 팀원에게는 비밀값, 사용자 개인정보, 필요 없는 코드를 보내지 않는다. 관련 구역만 보낸다.
- 지시서(`team/tasks/`)는 커밋하고, 팀원의 원본 답변(`team/out/`)은 커밋하지 않는다(.gitignore).

## 도구: `tools/team/team.py`
```
python3 tools/team/team.py ping   --to gpt|grok             # 연결 확인
python3 tools/team/team.py models --to gpt|grok             # 모델 목록
python3 tools/team/team.py new    T-001 "제목" --to gpt      # 지시서 양식 생성
python3 tools/team/team.py ask    --to gpt --task team/tasks/T-001.md \
        --ctx app/src/main/assets/index.html:1200-1350      # 작업 맡기기
python3 tools/team/team.py ask    ... --feedback team/tasks/T-001.피드백.md   # 재작업
python3 tools/team/team.py apply  team/out/T-001.gpt.1.md --dry            # 적용 미리보기
python3 tools/team/team.py apply  team/out/T-001.gpt.1.md                  # 적용
```
- 팀원 공통 규칙과 답변 형식: `tools/team/system_prompt.md`
- 모델·주소 설정: `tools/team/config.json`
- 답변은 SEARCH/REPLACE 블록 형식이다. 하나라도 원본과 맞지 않으면 **아무것도 바꾸지 않는다.**

## 환경
- API 키는 클라우드 환경(Default)의 네트워크 비밀값에 저장돼 있다(api.openai.com, api.x.ai). 프록시가 요청에 키를 넣어 주므로 코드와 저장소에는 키가 없다.
- **ChatGPT Plus·SuperGrok 구독과 API 크레딧은 별개다.** 크레딧은 platform.openai.com/settings/organization/billing 과 console.x.ai 에서 충전한다.
- 2026-11-27 설정 시점: 두 키 모두 인증은 됐지만 크레딧이 0이라 실제 호출은 막혀 있다. 충전한 뒤 `ping`으로 확인하고, `config.json`의 모델을 확정한다.
