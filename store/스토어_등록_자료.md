## 2. 스토어 등록정보

**짧은 설명 (80자 이내)**
```
워킹낚시용 물흐름·조석·물때를 한 지도에. 조류 예보와 항내 흐름 추정, 출조 도우미.
```

**자세한 설명**
```
바다흐름지도는 워킹낚시(갯바위·방파제·해변)를 위한 바다 정보 지도입니다.

■ 시간대별 물흐름
· 국립해양조사원 조류 예보(ROMS)를 지도 위 흐름선으로 보여줍니다.
· 시간 막대를 움직여 약 7일 뒤까지 흐름을 미리 볼 수 있습니다.
· ⚓ 항내 추정: 방파제 안쪽처럼 예보가 닿지 않는 곳의 흐름을 계산으로 추정합니다.

■ 조석·물때
· 가까운 조위 관측소의 만조·간조 시각, 지금 들물·날물 단계, 몇 물인지 보여줍니다.
· 간출암·노출암과 갯벌 범위를 표시하고, 바위가 언제 잠기는지 알려줍니다.

■ 바람
· 기상청 단기예보 바람과 표층 밀림을 함께 봅니다.

■ 출조 도우미
· ⭐ 오늘의 추천: 오늘의 황금 시간(물돌이 앞뒤 + 해뜰녘·해질녘), 한마디 조언, 갈 만한 곳
· 📅 3주 계획: 날짜별 물때·조차·승부 시간·해 뜨고 지는 시각
· 📍 지역 추천: 시·군·구를 고르면 유속·바위·물골·물때로 점수를 매겨 후보 해안과 내 즐겨찾기를 비교
· 📓 조과 기록: 입질 순간의 물때·유속·바람을 한 번에 기록, CSV 내보내기
· 🔔 안전 알림: 만조·바위 잠김 전에 알림

※ 공공데이터포털 인증키(무료)가 필요합니다. 설정(⚙)에 넣어 주세요.
※ 추천은 예보와 계산에 의한 참고 정보입니다. 진입로·낚시 금지 구역·현장 안전은 직접 확인하세요.

데이터: 국립해양조사원(조류·조석), 기상청(단기예보), 전자해도(간출암·조간대), 통계청 SGIS(행정구역) — 공공누리/이용허락 범위에 따름
```

## 3. 개인정보처리방침 (공개 주소에 올릴 글)

> 구글 사이트·노션 공개 페이지 등에 아래를 붙여넣고, 그 주소를 Play Console에 넣으세요. [연락 이메일]은 직접 채우세요.

```
바다흐름지도 개인정보처리방침
시행일: 2026년 11월 19일

1. 개발자는 별도의 서버를 운영하지 않으며, 이용자의 개인정보를 수집·보관·판매하지 않습니다.

2. 기기 안에만 저장하는 정보
 - 공공데이터포털 인증키, 앱 설정, 즐겨찾기, 조과 기록(시각·위치·물때·메모), 받은 예보 자료
 - 이 정보는 이용자의 휴대폰 안에만 저장되며 개발자에게 전송되지 않습니다. 앱을 지우면 함께 삭제됩니다.

3. 위치 정보
 - '현재 위치' 버튼을 누를 때 지도를 내 위치로 옮기고 조과 기록에 위치를 남기는 데만 사용합니다.
 - 위치는 개발자에게 전송되지 않습니다.

4. 예보 자료를 받기 위해 보내는 정보
 - 지도에 보이는 바다 구역의 좌표 범위와 이용자의 인증키를 아래 공공기관 서비스에 보내 예보를 받습니다.
   · 공공데이터포털(국립해양조사원 조류·조석 예보, 기상청 단기예보)
 - 지도 그림은 Esri·OpenStreetMap 타일 서버에서 받습니다. 이 과정에서 각 서비스에 일반적인 접속 정보(IP 주소 등)가 전달될 수 있으며, 각 기관·서비스의 개인정보 정책을 따릅니다.

5. 광고·분석 도구를 사용하지 않습니다.

6. 이용자가 '공유'를 누를 때만 기록(CSV)이나 백업이 이용자가 고른 앱으로 전달됩니다.

7. 문의: [연락 이메일]
```

## 5. 내부 테스트 올리기
1. 테스트 및 출시 → 테스트 → **내부 테스트** → 테스터 탭에서 이메일 목록 만들기(본인 Gmail)
2. 새 버전 만들기 → **Play 앱 서명**: Google에서 생성한 키 사용(기본값) 그대로
3. GitHub Releases의 최신 `fishmap-N.aab` 업로드 → 출시 이름은 자동 → 검토 후 출시
4. 테스터 탭의 **참여 링크**를 폰에서 열기 → 테스터 되기 → Play 스토어에서 설치
5. 설치 전에: 지금 앱 ⚙ → 💾 백업 내보내기 → 지금 앱 삭제 → 스토어 앱 설치 → ⚙ → 📥 백업 가져오기
